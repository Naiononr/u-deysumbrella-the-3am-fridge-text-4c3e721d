The 3AM Fridge Text — a pure-stdlib Python program that writes the one line a smart fridge would text its owner at 3am to `entry.txt`:

> 3am. I counted your midnight snacks. All four of them. We need to talk about the pickles.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` (deterministic — repeated runs are byte-identical). No dependencies beyond the Python standard library, no network at runtime.
